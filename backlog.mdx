## Alcance del Sprint 3

- Inicio de sesión y cierre de sesión (Administrador / Árbitro).
- Control de acceso por rol (Administrador / Árbitro).
- Gestión de Usuarios (CRUD): crear, editar, listar y borrar (Administrador).
- Gestión de Partidos (CRUD): crear, editar, listar y borrar (Administrador / Árbitro para listar).
- Gestión de Liquidaciones (CRUD): crear, editar, listar y borrar (Administrador / Árbitro para listar).
- Gestión de Licencias (CRUD): crear, editar, listar y borrar (Administrador).
- Gestión de Árbitros: editar y listar (Administrador).
- Gestión de Disponibilidad: crear y listar (Árbitro), consultar disponibilidad (Administrador).
- Gestión de Mi Perfil (Administrador / Árbitro).
- Gestión de Rectificaciones: crear (Árbitro), editar y listar (Administrador).
- Listado de Compañeros (Árbitros).
- Accesibilidad de la Página (WCAG AAA).
- Estructura MVC operativa, con modelos, vistas y controladores.
- Base de datos MySQL con scripts: `bbdd.sql`, `datos.sql`.
- Estáticos organizados: CSS y JS.
- Manejo de errores, logs mínimos y seguridad esencial (sesiones seguras y consultas preparadas).
