## Historias de Usuario y Criterios de Aceptación

### CU-01 — Inicio de Sesión (Administrador / Árbitro)
Como usuario registrado, quiero iniciar sesión con mi correo y contraseña para acceder a la aplicación según mi rol.

Criterios de aceptación:
- Dado que estoy en la pantalla de login, cuando ingreso un correo y contraseña válidos, entonces accedo al dashboard correspondiente a mi rol.
- Dado que ingreso credenciales inválidas, cuando intento iniciar sesión, entonces veo un mensaje claro de error sin revelar detalles sensibles.

---

### CU-02 — Cerrar Sesión (Administrador / Árbitro)
Como usuario autenticado, quiero cerrar sesión para finalizar mi acceso a la aplicación.

Criterios de aceptación:
- Dado que estoy autenticado, cuando hago clic en "Cerrar sesión", entonces se destruye la sesión y soy redirigido a la pantalla de login.
- Dado que cierro sesión, cuando intento volver con el botón atrás, entonces no puedo acceder a páginas protegidas.

---

### CU-03 — Control de Acceso por Rol (Administrador / Árbitro)
Como sistema, debo restringir el acceso a rutas y acciones según rol (Administrador, Árbitro).

Criterios de aceptación:
- Dado que soy Árbitro, cuando intento acceder a funciones de administración, entonces el sistema lo impide y muestra mensaje de acceso denegado.
- Dado que soy Administrador, cuando accedo a cualquier módulo de gestión, entonces puedo realizar todas las acciones permitidas.

---

### CU-04 — Crear usuarios (Administrador)
Como Administrador, quiero crear nuevos usuarios para gestionar el acceso a la plataforma.

Criterios de aceptación:
- Dado que estoy autenticado como Administrador, cuando completo el formulario con datos válidos, entonces el usuario queda guardado en la base de datos.
- Dado que algunos campos obligatorios están vacíos o inválidos, cuando envío el formulario, entonces veo mensajes de validación claros.

---

### CU-05 — Editar usuarios (Administrador)

Criterios de aceptación:

- Dado que guardo cambios válidos, cuando confirmo, entonces se persisten y la lista refleja la actualización.

---

### CU-06 — Listar usuarios (Administrador)

Criterios de aceptación:

- Dado que aplico filtros o búsqueda, cuando los envío, entonces la tabla se actualiza mostrando solo los registros filtrados.

- Dado que tengo dificultades visuales, cuando uso la aplicación, entonces el contraste y tamaño de fuente son adecuados.
- Dado que navego con teclado, cuando uso Tab y Enter, entonces puedo acceder a todas las funciones.

---

### CU-31 — Cambio de Contraseña (Administrador / Árbitro)
Como usuario autenticado, quiero cambiar mi contraseña para mantener la seguridad de mi cuenta.

Criterios de aceptación:
- Dado que estoy autenticado, cuando accedo a la opción de cambiar contraseña, entonces veo un formulario con los campos necesarios.
- Dado que introduzco mi contraseña actual correcta y una nueva contraseña válida, cuando confirmo el cambio, entonces la contraseña se actualiza correctamente.
- Dado que introduzco una contraseña actual incorrecta, cuando intento cambiarla, entonces veo un mensaje de error indicando que la contraseña actual no es correcta.
- Dado que la nueva contraseña no cumple los requisitos de seguridad, cuando intento guardar, entonces veo un mensaje indicando los requisitos mínimos.
- Dado que la confirmación de la nueva contraseña no coincide, cuando intento guardar, entonces veo un mensaje de error indicando que las contraseñas no coinciden.
