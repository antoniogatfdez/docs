## 1. Introducción

Este documento describe la API interna del sistema de gestión de árbitros Sprint-3, documentada siguiendo los estándares **PHPDoc** para el código PHP y **JSDoc** para el código JavaScript.

La documentación incluye:
- Descripción de clases y métodos
- Parámetros de entrada y tipos de retorno
- Ejemplos de uso cuando es pertinente
- Relaciones entre componentes

---

## 2. Documentación PHP (PHPDoc)

### 2.1 Modelos

Los modelos se encuentran en `src/www/modelos/` y extienden de `ModeloBase`.

---

#### ModeloBase

```php
/**
 * Clase base para modelos: centraliza la conexión PDO y utilidades comunes.
 * 
 * Proporciona la configuración de conexión a la base de datos MySQL
 * con opciones de seguridad y manejo de errores.
 * 
 * @package    Modelos
 * @author     Sprint-3
 * @version    1.0
 */
class ModeloBase {
    /**
     * Instancia de conexión PDO.
     * 
     * @var PDO
     */
    protected $conexion;

    /**
     * Constructor - inicializa la conexión a base de datos.
     */
    public function __construct();

    /**
     * Crea y devuelve una instancia PDO configurada.
     * 
     * Configura la conexión con:
     * - Modo de error: excepciones
     * - Modo de fetch: arrays asociativos
     * - Emulación de prepares desactivada
     * 
     * @return PDO Instancia de conexión configurada
     * @throws PDOException Si falla la conexión
     */
    protected function crearConexion(): PDO;
}
```

#### ModeloUsuario

```php
/**
 * ModeloUsuario: operaciones relacionadas con la tabla usuarios.
 * 
 * Gestiona la información básica de autenticación, tipo de usuario
 * y operaciones CRUD completas sobre usuarios del sistema.
 * 
 * @package    Modelos
 * @extends    ModeloBase
 * @author     Sprint-3
 * @version    1.0
 */
class ModeloUsuario extends ModeloBase {
    /**
     * Obtiene un usuario activo por nombre de usuario.
     * 
     * @param string $usuario Nombre de usuario a buscar
     * @return array|null Datos del usuario o null si no existe
     * 
     * @example
     * $modelo = new ModeloUsuario();
     * $usuario = $modelo->obtenerPorUsuario('admin');
     */
    public function obtenerPorUsuario(string $usuario): ?array;

    /**
     * Registra un nuevo usuario en el sistema.
     * 
     * @param string $usuario         Nombre de usuario único
     * @param string $email           Correo electrónico
     * @param string $passwordPlano   Contraseña en texto plano (será hasheada)
     * @param string $tipoUsuario     Tipo: 'administrador' o 'arbitro'
     * @param bool   $passwordTemporal Si la contraseña es temporal
     * @return int ID del usuario creado
     * 
     * @throws PDOException Si el usuario ya existe
     */
    public function crear(
        string $usuario, 
        string $email, 
        string $passwordPlano, 
        string $tipoUsuario = 'administrador', 
        bool $passwordTemporal = false
    ): int;

    /**
     * Obtiene un usuario por su identificador primario.
     * 
     * @param int $id Identificador del usuario
     * @return array|null Datos del usuario o null si no existe
     */
    public function obtenerPorId(int $id): ?array;

    /**
     * Lista todos los usuarios activos.
     * 
     * @return array<int,array> Lista de usuarios ordenados por nombre
     */
    public function listarTodos(): array;

    /**
     * Actualiza los datos básicos de un usuario.
     * 
     * @param int    $id          Identificador del usuario
     * @param string $usuario     Nuevo nombre de usuario
     * @param string $email       Nuevo correo electrónico
     * @param string $tipoUsuario Tipo de usuario
     * @return bool True si la actualización fue exitosa
     */
    public function actualizar(int $id, string $usuario, string $email, string $tipoUsuario): bool;

    /**
     * Actualiza parcialmente los datos de un usuario.
     * 
     * @param int   $id    ID del usuario
     * @param array $datos Array asociativo con campos a actualizar
     * @return bool True si la actualización fue exitosa
     */
    public function actualizarParcial(int $id, array $datos): bool;

    /**
     * Cambia la contraseña de un usuario.
     * 
     * @param int    $id            ID del usuario
     * @param string $nuevaPassword Nueva contraseña en texto plano
     * @return bool True si el cambio fue exitoso
     */
    public function cambiarPassword(int $id, string $nuevaPassword): bool;

    /**
     * Establece una contraseña temporal para un usuario.
     * 
     * @param int    $id               ID del usuario
     * @param string $passwordTemporal Contraseña temporal
     * @return bool True si fue exitoso
     */
    public function establecerPasswordTemporal(int $id, string $passwordTemporal): bool;

    /**
     * Elimina lógicamente un usuario (activo=0).
     * 
     * @param int $id ID del usuario a eliminar
     * @return bool True si fue exitoso
     */
    public function eliminarPorId(int $id): bool;

    /**
     * Verifica si un nombre de usuario ya existe.
     * 
     * @param string   $usuario   Nombre de usuario
     * @param int|null $exceptoId ID a excluir (para edición)
     * @return bool True si existe
     */
    public function existeUsuario(string $usuario, ?int $exceptoId = null): bool;
}
```

    /**

/**
