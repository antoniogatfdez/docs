## Enrutamiento y flujo de ejecución

El enrutamiento se gestiona mediante el Front Controller `index.php`:

```php
$ruta = $_GET['ruta'] ?? 'login';
$accion = $_POST['accion'] ?? ($_GET['accion'] ?? null);

// Verificar cambio de contraseña obligatorio
if (ControladorAutenticacion::autenticado() && 
    ($_SESSION['password_temporal'] ?? false) && 
    $ruta !== 'cambiar_password' && $ruta !== 'logout') {
    header('Location: index.php?ruta=cambiar_password');
    exit;
}

switch ($ruta) {
    case 'login':        // Autenticación
    case 'logout':       // Cierre de sesión
    case 'cambiar_password':  // Cambio de contraseña
    case 'dashboard':    // Panel principal (según rol)
    case 'perfil':       // Perfil de usuario
    case 'partidos':     // CRUD partidos (admin)
    case 'mis_partidos': // Partidos del árbitro
    case 'usuarios':     // CRUD usuarios (admin)
    case 'arbitros':     // Gestión árbitros (admin)
    case 'lista_arbitros': // Listado compañeros (árbitro)
    case 'licencias':    // CRUD licencias (admin)
    case 'liquidaciones': // Gestión liquidaciones (admin)
    case 'mis_liquidaciones': // Liquidaciones (árbitro)
    case 'disponibilidad_arbitros': // Consulta disponibilidad (admin)
    case 'disponibilidad': // Registrar disponibilidad (árbitro)
    case 'api':          // Endpoints AJAX
    case 'unauthorized': // Acceso denegado
    default:             // 404
}
```

### Convenciones de enrutamiento

- `ruta`: define el recurso principal (ej. `partidos`, `usuarios`)
- `accion`: especifica la operación CRUD (ej. `crear`, `actualizar`, `eliminar`)
- Control de acceso por rol antes de ejecutar acciones sensibles
- Patrón PRG (Post/Redirect/Get) para evitar reenvíos de formularios

## Modelos y acceso a datos (PDO)

### ModeloBase - Conexión centralizada

```php
class ModeloBase {
    protected PDO $conexion;

    public function __construct() {
        $this->conexion = $this->crearConexion();
    }

    protected function crearConexion(): PDO {
        $dsn = 'mysql:host=' . BD_HOST . ';dbname=' . BD_NOMBRE . ';charset=utf8mb4';
        return new PDO($dsn, BD_USUARIO, BD_PASSWORD, [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES => false,
        ]);
    }
}
```

### Buenas prácticas aplicadas

- ✅ Consultas preparadas para evitar inyección SQL
- ✅ `FETCH_ASSOC` por defecto para arrays asociativos
- ✅ `utf8mb4` para compatibilidad con emojis y caracteres especiales
- ✅ Transacciones en operaciones múltiples (licencias, liquidaciones)
- ✅ Eliminación lógica (`activo = 0`) en lugar de física

## Controladores y validación

### Ejemplo: ControladorPartido

```php
class ControladorPartido {
    private ModeloPartido $modeloPartido;

    public function __construct() {
        $this->modeloPartido = new ModeloPartido();
        if (!ControladorAutenticacion::autenticado()) {
            header('Location: index.php');
            exit;
        }
    }

    public function crear(): void {
        $datos = $this->sanearDatos($_POST);
        if ($this->validarDatos($datos)) {
            $this->modeloPartido->crear($datos);
            $_SESSION['flash'] = ['mensaje' => 'Partido creado correctamente.', 'exito' => true];
        } else {
            $_SESSION['flash'] = ['mensaje' => 'Datos inválidos.', 'exito' => false];
        }
        header('Location: index.php?ruta=partidos');
        exit;
    }

    private function sanearDatos(array $d): array {
        $limpios = [];
        foreach ($d as $k => $v) {
            $limpios[$k] = is_string($v) ? trim(htmlspecialchars($v, ENT_QUOTES, 'UTF-8')) : $v;
        }
        // Unificar fecha + hora
        if (isset($d['fecha_dia'], $d['fecha_hora'])) {
            $limpios['fecha'] = $d['fecha_dia'] . ' ' . $d['fecha_hora'] . ':00';
        }
        return $limpios;
    }

    private function validarDatos(array $datos): bool {
        $requeridos = ['equipo_local', 'equipo_visitante', 'categoria_id', 'fecha', 'pabellon_nombre'];
        foreach ($requeridos as $campo) {
            if (empty($datos[$campo])) return false;
        }
        return strcasecmp($datos['equipo_local'], $datos['equipo_visitante']) !== 0;
    }
}
```

## Autenticación, sesiones y roles

### Inicio de sesión

```php
public function iniciarSesion(): void {
    $usuario = trim($_POST['usuario'] ?? '');
    $password = $_POST['password'] ?? '';
    
    $registro = $this->modeloUsuario->obtenerPorUsuario($usuario);
    if ($registro && password_verify($password, $registro['password'])) {
        $_SESSION['usuario_id'] = $registro['id'];
        $_SESSION['usuario_nombre'] = $registro['usuario'];
        $_SESSION['tipo_usuario'] = $registro['tipo_usuario'];
        $_SESSION['password_temporal'] = (bool)($registro['password_temporal'] ?? false);
        
        if ($_SESSION['password_temporal']) {
            header('Location: index.php?ruta=cambiar_password');
        } else {
            header('Location: index.php?ruta=dashboard');
        }
        exit;
    }
    $this->redirigirConMensaje('Usuario o contraseña incorrectos.', false);
}
```

### Variables de sesión

| Variable | Tipo | Descripción |
|----------|------|-------------|
| `usuario_id` | int | ID del usuario autenticado |
| `usuario_nombre` | string | Nombre de usuario |
| `tipo_usuario` | string | `administrador` o `arbitro` |
| `password_temporal` | bool | Si debe cambiar contraseña |
| `flash` | array | Mensajes flash (mensaje, exito/tipo) |

### Protección de rutas

```php
// En index.php, antes de cada ruta sensible
if (($_SESSION['tipo_usuario'] ?? '') !== 'administrador') {
    header('Location: index.php');
    exit;
}
```

## Estándares y buenas prácticas

### Nomenclatura

- Clases en `PascalCase`: `ModeloUsuario`, `ControladorPartido`
- Métodos en `camelCase`: `obtenerPorId()`, `listarTodos()`
- Variables en `camelCase`: `$usuarioId`, `$fechaInicio`
- Constantes en `SCREAMING_SNAKE_CASE`: `BD_HOST`, `APP_DEPURACION`
- Archivos en `snake_case`: `modelo_usuario.php`, `controlador_partido.php`

### Clean Code

- ✅ Funciones cortas con responsabilidad única
- ✅ Nombres descriptivos y autoexplicativos
- ✅ Comentarios PHPDoc/JSDoc en clases y métodos
- ✅ Manejo de errores centralizado
- ✅ Evitar duplicación de lógica

### Reglas rápidas

1. Siempre usar consultas preparadas para datos externos
2. Validar entrada en controladores, revalidar en modelos si aplica
3. No acceder a `$_POST`/`$_GET` directamente en vistas
4. Usar mensajes flash para feedback al usuario
5. Aplicar patrón PRG (Post/Redirect/Get)
6. Documentar código con PHPDoc y JSDoc

## Cómo añadir nuevas funcionalidades

### 1. Base de datos

```sql
-- Añadir en src/sql/bbdd.sql
CREATE TABLE nueva_entidad (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    activo TINYINT(1) DEFAULT 1,
    fecha_creacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2. Modelo

```php
// src/www/modelos/modelo_nueva_entidad.php
<?php
require_once __DIR__ . '/modelo_base.php';

/**
 * ModeloNuevaEntidad: operaciones CRUD.
 * @package Modelos
 */
class ModeloNuevaEntidad extends ModeloBase {
    public function listarTodos(): array {
        return $this->conexion->query('SELECT * FROM nueva_entidad WHERE activo = 1')->fetchAll();
    }

    public function crear(array $datos): int {
        $stmt = $this->conexion->prepare('INSERT INTO nueva_entidad (nombre) VALUES (:nombre)');
        $stmt->execute([':nombre' => $datos['nombre']]);
        return (int)$this->conexion->lastInsertId();
    }
}
```

### 3. Controlador

```php
// src/www/controladores/controlador_nueva_entidad.php
<?php
require_once __DIR__ . '/../modelos/modelo_nueva_entidad.php';

/**
 * ControladorNuevaEntidad: orquestación CRUD.
 * @package Controladores
 */
class ControladorNuevaEntidad {
    private ModeloNuevaEntidad $modelo;

    public function __construct() {
        $this->modelo = new ModeloNuevaEntidad();
    }

    public function listado(): void {
        $items = $this->modelo->listarTodos();
        $flash = $_SESSION['flash'] ?? null;
        unset($_SESSION['flash']);
        require __DIR__ . '/../vistas/nueva_entidad_listado.php';
    }

    public function crear(): void {
        // Validar, insertar, flash, redirect
    }
}
```

### 4. Vista


## Depuración y registro de errores

### Configuración

```php
// config.php
define('APP_DEPURACION', false);  // TRUE en desarrollo

set_error_handler(function ($errno, $errstr, $errfile, $errline) {
    if (!APP_DEPURACION) {
        error_log("[ERROR] $errstr en $errfile:$errline");
        return true;
    }
    return false;
});

set_exception_handler(function ($ex) {
    error_log('[EXCEPCIÓN] ' . $ex->getMessage());
    if (APP_DEPURACION) {
        echo '<pre>' . htmlspecialchars($ex->getMessage()) . '</pre>';
    } else {
        echo MSJ_ERROR_GENERAL;
    }
});
```

### Registro de eventos
